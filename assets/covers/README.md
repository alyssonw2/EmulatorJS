# Capas dos Jogos

Adicione as imagens de capa dos jogos nesta pasta com os seguintes nomes:

- `kof97pls.jpg` - The King of Fighters '97 Plus
- `mk2.jpg` - Mortal Kombat II
- `mslug.jpg` - Metal Slug
- `mslug4.jpg` - Metal Slug 4
- `mslug5.jpg` - Metal Slug 5

## Formato recomendado:
- Formato: JPG ou PNG
- Resolução: 640x480 ou maior
- Proporção: 4:3 ou 16:9

## Fontes para capas:
- https://www.mobygames.com/
- https://www.screenscraper.fr/
- https://thegamesdb.net/

Você pode usar qualquer imagem de screenshot ou arte promocional dos jogos.
